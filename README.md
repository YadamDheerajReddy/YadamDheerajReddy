- 🌐 **[Strata](https://github.com/YadamDheerajReddy/Strata-Browser)** — a local-first desktop browser on real Chromium (CEF) that quietly remembers your tabs, layout, and scroll position, so you can pick up a workspace right where you left it. No account, no cloud, nothing leaves your machine.
- 💪 **[AuraFit AI](https://github.com/YadamDheerajReddy/aurafit-ai)** — a fully local calorie and body-transformation tracker. Every AI inference runs on-device via Ollama; zero network calls, zero subscription.
- 🎓 **[ExamGuard](https://github.com/YadamDheerajReddy/exam-guard)** — a smart exam-hall allocation and identity-verification system: time-gated seat reveals, rotating barcode passes, and an offline-first invigilator scanner with a tamper-evident audit trail.
- 🖥️ **[ECHO](https://github.com/YadamDheerajReddy/ECHO-Everyday_Computing_Human_Operator)** — an AI-native command palette for Windows. One hotkey brings up a fully local AI assistant, clipboard intelligence, voice input, and workflow automation — all offline by default.
